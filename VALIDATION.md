## Почему APK не вложен

В контейнере сборки отсутствуют Flutter SDK, Dart SDK и Android SDK, поэтому честно подтвердить APK-компиляцию здесь невозможно. Проект подготовлен под установленный у владельца Flutter 3.44.5. На Windows окончательная проверка выполняется командами:

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Debug APK предназначен для проверки, а не для публикации. Для RuStore требуется личный release-keystore владельца.

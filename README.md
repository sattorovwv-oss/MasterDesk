# MasterDesk — Моя мастерская

Офлайн-приложение NEXVIRO для небольшой ремонтной мастерской. Проект написан на Flutter и рассчитан прежде всего на Android-телефоны и планшеты.

## Что реализовано

- первый запуск с выбором русского/английского языка, данных мастерской и валюты;
- светлая, тёмная и системная темы;
- локальная SQLite-база без регистрации и сервера;
- клиенты, поиск и история количества заказов/долга;
- четырёхшаговый приём устройства и атомарный номер `MD-000001`;
- статусы ремонта, сроки, приоритеты и история событий;
- услуги/запчасти в заказе, оплаты и возвраты;
- склад с поступлением, списанием и защитой от отрицательного остатка;
- задачи, сотрудники, каталог услуг, расходы, финансы и отчёт по статусам;
- PDF заказ-наряда с кириллицей и английским текстом;
- CSV заказов;
- резервная копия и транзакционное восстановление JSON;
- адаптивная нижняя навигация/NavigationRail;
- денежные расчёты в целых минимальных единицах;
- тесты парсинга, форматирования, округления и расчётов.

## Подтверждённые ограничения версии 1.0

- приложение работает с одной мастерской на одном устройстве;
- банковские платежи не проводятся — фиксируется факт оплаты;
- нет аккаунтов, облачной синхронизации и кабинета клиента;
- фото устройств, фоновые локальные уведомления, PIN/биометрия и полный FIFO по закупочным партиям ещё не включены;
- резервная копия содержит данные SQLite; внешних вложений в этой версии нет;
- Android release использует debug-подпись только для локальной проверки. Для RuStore нужен личный release-keystore владельца.

## Требования

- Windows 10/11 x64;
- Flutter 3.44.5 stable или совместимая более новая стабильная версия;
- Android SDK, JDK 17;
- VS Code с расширениями Flutter и Dart;
- Android-устройство с Android 6.0+ (API 23+), включённой USB-отладкой.

Проверка окружения:

```powershell
flutter doctor -v
adb devices
```

## Запуск на телефоне

Распакуйте архив, откройте PowerShell в папке `MasterDesk` и выполните:

```powershell
flutter clean
flutter pub get
flutter analyze
flutter test
flutter run
```

После запуска изменения кода можно применять клавишей `r` (hot reload), полный перезапуск — `R`.

## Сборка APK

Debug APK для проверки:

```powershell
flutter build apk --debug
```

Файл появится здесь:

```text
build\app\outputs\flutter-apk\app-debug.apk
```

Release APK с текущей тестовой подписью:

```powershell
flutter build apk --release
```

Этот release нельзя публиковать в магазине. Перед публикацией создайте собственный keystore, добавьте `android/key.properties` локально и замените signingConfig в `android/app/build.gradle.kts`. Не отправляйте keystore и пароли в GitHub или Telegram.

## Проверка основных сценариев

1. Запустите приложение и настройте мастерскую.
2. Создайте клиента и заказ на 300 TJS с предоплатой 100 TJS.
3. В карточке заказа проверьте остаток 200 TJS.
4. Добавьте оплату 200 TJS — остаток станет 0.
5. Добавьте на склад 5 деталей и спишите 1 — остаток станет 4.
6. Создайте PDF из карточки заказа.
7. В настройках создайте резервную копию, затем выберите её для восстановления.

  services/   PDF, CSV, backup
  widgets/    общие компоненты
test/         тесты бизнес-правил

## Обновление сборки Codemagic

Для совместимости с актуальным Flutter stable Android-toolchain проекта обновлён до Gradle 8.14.5, AGP 8.11.1 и Kotlin 2.2.20. AGP 9 намеренно не используется, чтобы не включать новый Android DSL, который пока может конфликтовать с Flutter 3.47.x.

В корне также добавлен `codemagic.yaml` с готовым workflow `masterdesk-android-release`. Он использует Flutter 3.47.2 и Java 17 и собирает release APK в `build/app/outputs/flutter-apk/`.

Новая иконка MasterDesk находится в `assets/images/masterdesk_icon.png` и установлена как Android launcher icon вместо стандартной/временной иконки.
